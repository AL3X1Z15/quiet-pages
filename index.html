A little help

1. Set up iCloud Drive

Open Settings on your iPhone or iPad. Tap your name, then iCloud, then Drive or iCloud Drive. Turn on Sync this iPhone/iPad. Open Files → Browse → iCloud Drive. Tap the three-dot menu, choose New Folder, and name it Quiet Pages. This is a one-time setup.

2. Save a backup

Choose Everything, a journal, or the current page, then tap Back up / share file above. In the sharing menu choose Save to Files, then iCloud Drive → Quiet Pages → Save. If a download starts instead, look for the file in Files → Downloads and move it into your iCloud folder. Open Files and check that the dated file is there, then return here and tap I checked my backup in Files.

3. Optional: make an Apple Shortcut

Open Shortcuts and tap +. Name the new shortcut Back Up My Journal. In its details, turn on Show in Share Sheet. Set its accepted input to Files. Add the Save File action, using Shortcut Input as the file. Turn off Ask Where to Save if offered, and pick your Quiet Pages folder in iCloud Drive. Save the shortcut. Next time you share a backup, choose Back Up My Journal instead of Save to Files. Check the result in Files. Menu names can vary; if it does not work, use the manual method in step 2.

This shortcut is optional and must be tested on your device. It cannot fetch entries automatically.

4. Find or restore a journal

Open Files → Browse → iCloud Drive → Quiet Pages. Choose your latest full backup to recover all journals. Individual journal and page backups contain only their selected contents. To restore, open this app on the desired device, go to Storage & help, tap Restore / import backup, and choose the file. Existing pages are kept. Identical pages are skipped and differing versions of the same page are preserved as separate copies. This is not live synchronization.

5. Read your writing without the app

Export readable journal creates one HTML file containing your entries, text formatting, basic paper colours and embedded drawings or photos. Save it to iCloud Drive. It can be opened separately in a browser. Keep the JSON backup too; the readable file is not for restoring entries.

6. How often? Is it private?

Every 3–7 days is a useful starting point. A full backup contains everything as of the moment it was made. A partial backup does not reset the full-backup reminder. Your device saves changes automatically, but clearing app data or losing your phone can erase local entries. No journal is uploaded by Quiet Pages; iCloud stores the copies you save there. These files are not encrypted by this app. Avoid shared folders and keep your device secured.
